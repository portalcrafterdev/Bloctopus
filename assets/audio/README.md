# Audio

Every file in this folder is generated by `tool/generate_audio.dart`:

```
dart run tool/generate_audio.dart
```

It synthesises each sound from sine partials, filtered noise and envelopes.
Nothing here is sampled, recorded, or derived from another game, which is what
sections 11.3 and 16 require. The generated files are committed so a clean
checkout builds a game with sound.

## What ships

The full list from section 11.1: `pickup`, `place`, `invalid`, `clear_1` to
`clear_8`, `combo`, `booster`, `ink`, `star`, `level_win`, `level_fail`,
`blub`, `tap`, `music_menu`, `music_game`.

The pitch ladder in section 11.2 is real. `clear_1` to `clear_8` walk a C major
scale from C5 to C6, so three lines cleared at once, staggered 70ms apart,
arpeggiate upward.

## Two deviations from section 11.3

Both are forced by generating audio in pure Dart, and both are reversible.

**Format is WAV, not OGG/M4A.** Encoding either needs a codec Dart does not
have, and shelling out to ffmpeg would make the build depend on a tool nothing
else needs. Android and iOS both decode WAV natively.

**Sample rate is 22.05kHz, not 44.1kHz.** WAV is uncompressed, so at 44.1kHz
the longer cues would exceed the 40 KB per file budget. 22.05kHz reproduces
everything up to 11kHz, comfortably above the highest partial any of these
sounds carries. Every file is inside budget: the largest SFX is 32 KB against
the 40 KB limit, and each music loop is 689 KB against the 1.2 MB limit.

## Replacing these with commissioned audio

These are honest placeholders. They are tuned to be soft and non-fatiguing, but
a composer will do better. To swap them:

1. Deliver OGG (Android) and M4A (iOS) files using exactly the names above.
2. Restore the per-platform extension in `lib/game/audio.dart`:
   `!kIsWeb && Platform.isIOS ? 'm4a' : 'ogg'`.

Nothing else changes. Keep `clear_1` to `clear_8` as one sample at eight
pitches, or the ladder stops reading as one instrument.

If you source rather than commission, use CC0 only: Freesound (filtered to CC0)
or the Kenney.nl audio packs. Never extract audio from another game.
